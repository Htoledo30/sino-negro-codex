# Hospedagem de Sino Negro

O projeto está preparado para publicação estática HTTPS. O processo de publicação desta entrega usa o plugin Sites. O estado efetivo e o endereço verificado serão registrados neste arquivo após o retorno da hospedagem.

O serviço mantém o jogo privado para o proprietário da conta. O primeiro acesso pode pedir autenticação. O gameplay não usa essa conta nem requer backend próprio.

O README contém comandos de desenvolvimento, build, instalação no iPhone e publicação independente pelo GitHub Pages. O conteúdo de `dist/` pode ser hospedado em qualquer serviço estático HTTPS.
